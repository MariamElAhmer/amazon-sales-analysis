# Amazon Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze Amazon sales performance and provide insights into products, employees, regions, and shipping operations.

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- KPI Analysis

## Dashboard Pages

### 1. Performance Overview
- Total Sales
- Total Orders
- Total Quantity
- Total Customers
- Average Order Value
- Monthly Sales Trends

### 2. Sales Analysis
- Sales by Category
- Top and Bottom Performing Categories
- Product Performance Analysis

### 3. Employee Analysis
- Employee Sales Contribution
- Top Performing Employees
- Average Sales per Employee

### 4. Regional Analysis
- Sales by Territory
- Sales by Region
- Geographic Sales Distribution

### 5. Shipping Analysis
- Quantity by Shipping Company
- Quantity by Product Category
- Shipping Performance Trends

## Repository Structure
- `powerbi/`: Original Power BI dashboard file.
- `screenshots/`: Dashboard previews.

## Project Objective
To transform sales data into interactive visual insights that support business performance monitoring and data-driven decision-making.
